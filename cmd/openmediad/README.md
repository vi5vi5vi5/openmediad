# cmd/openmediad — бинарник колонки

`main.go` — одна строка: `os.Exit(cli.Main(os.Args[1:]))`. Склейка: пакет `catalog` передаёт ядру паспорта компонентов, пакет `included`
подключает те компоненты, чей тег сборки задан (`omd_<имя>`).

Собирать нужно через `go run ./tools/build` (профиль `standard`; `-profile core|full`, `-with`, `-without`). Голый `go build` без тегов даёт
только ядро — прозрачного посредника без компонентов.
