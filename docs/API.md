# API движка: как добавить свою функцию

Свою функцию к движку можно добавить двумя способами. Выбор простой: если хватает команд и событий — пишите программу снаружи; если нужен
звук, свой источник музыки или перехват фраз — пишите компонент.

| Способ | Что можно | Пересборка движка |
|---|---|---|
| [Программа снаружи](#1-программа-снаружи-сокет-команд) (любой язык) | команды плееру, «кто играет», события, фраза Алисе, состояние и журнал | не нужна |
| [Компонент на Go](#2-компонент-на-go) | всё: свой звук в движок, свой плеер, свой выход, перехват фраз, свои команды терминала | нужна |

## 1. Программа снаружи: сокет команд

Демон слушает unix-сокет `/tmp/openmediad/ctl.sock` (другой каталог — переменная `OPENMEDIAD_RUN`; доступ только у root). Запрос — одна строка
JSON, ответ — строки `{"ok":true,"data":…}` или `{"ok":false,"error":"…"}`. Проще всего пользоваться самим бинарником: каждая команда сокета
есть и в терминале, и с ключом `-json` печатает ответ как есть.

| Нужно | В терминале | Запрос в сокет |
|---|---|---|
| команда плееру | `openmediad player pause\|resume\|toggle\|next\|prev` | `{"cmd":"control","action":"next"}` |
| кто играет | `openmediad player [-json]` | `{"cmd":"players"}` |
| события по мере появления | `openmediad events [-json]` | `{"cmd":"events"}` |
| фраза Алисе, как голосом | `openmediad ask включи свет` | `{"cmd":"ask","text":"включи свет"}` |
| состояние движка | `openmediad status [-v] [-json]` | `{"cmd":"status","detail":true}` |
| журнал | `openmediad logs [-f] [-json]` | `{"cmd":"logs","limit":100}`, `{"cmd":"follow"}` |
| перечитать настройки | `openmediad config update` | `{"cmd":"reload"}` |

С компьютера то же самое — через ssh: `ssh -p 2222 root@колонка openmediad player next`.

### Команда плееру

`control` — это тот же путь, что у кнопок наушников: один вызов ядра `Hub.Command`. Чей сейчас звук, решать не вам:

- играет плеер движка (Spotify) — команду выполнит он;
- играет музыка платформы (Яндекс.Музыка) или ничего не играет — команда уйдёт платформе, как нажатие кнопки на колонке.

Ответ говорит, кто выполнил: `{"action":"next","by":"spotify-soloist"}` или `"by":"platform-music"`.

### Кто играет

```json
{"owner":"spotify-soloist","dialog":false,"platform_playing":false,
 "players":[{"name":"spotify-soloist","ready":true,"playing":true,"sounding":true,"paused":false,"resumable":false,"track":"spotify:track:…"}],
 "platform":[]}
```

`owner` — кто последним начал играть (ему достанется «продолжи»); `dialog` — идёт диалог с Алисой, музыка приглушена; `players` — плееры движка;
`platform` — плееры, которые движок ведёт для платформы (музыка Яндекса с названием и позицией, голос, звонки).

### События

Одна строка JSON на событие, пока соединение открыто:

```json
{"type":"player","at_ms":1794250000123,"action":"pause","from":"headphones","player":"spotify-soloist"}
{"type":"player","at_ms":1794250004456,"action":"next","from":"fast","player":"spotify-soloist","platform_display":true,"platform_ring":true}
{"type":"dialog","at_ms":1794250009000,"on":true}
```

| Поле | Значения |
|---|---|
| `type` | `player` — пауза, продолжение, перемотка; `dialog` — диалог с Алисой начался (`on: true`) или кончился |
| `action` | `pause`, `resume`, `next`, `prev` — что сделано (а не что просили: «переключатель» приходит как пауза или продолжение) |
| `from` | `speaker` кнопка и жесты колонки, `headphones` кнопки наушников, `voice` фраза с «Алиса», `fast` короткая команда без «Алиса», `cloud` директива облака, `virtual` команда платформы, `arbiter` уступка звука другому источнику, `app` изменилось само (приложение Spotify, другое устройство), `api` команда из сокета |
| `player` | имя плеера движка или `platform-music` (команду музыке платформы передало ядро) |
| `platform_display`, `platform_ring` | прошивка сама покажет это действие на дисплее и на кольце логотипа; свою анимацию поверх рисовать не нужно |

События о музыке платформы приходят только для команд, которые ей передало ядро (кнопки наушников, сокет). Паузу, которую платформа поставила
своей музыке сама (голосом, кнопкой колонки), ядро пока не объявляет.

Пример на оболочке колонки — писать в файл каждую смену трека:

```sh
openmediad events -json | while read -r e; do
	case "$e" in *'"action":"next"'*|*'"action":"prev"'*) echo "$e" >> /tmp/skips.log ;; esac
done
```

Пример на Python (на колонке его нет; с компьютера — через ssh):

```python
import json, subprocess
p = subprocess.Popen(["ssh", "-p", "2222", "root@колонка", "openmediad", "events", "-json"], stdout=subprocess.PIPE, text=True)
for line in p.stdout:
    e = json.loads(line)
    if e["type"] == "dialog":
        print("Алиса слушает" if e.get("on") else "диалог кончился")
```

### Фраза Алисе

`ask` передаёт Алисе текст так, как если бы его произнесли: она ответит голосом и выполнит просьбу. Этим удобно делать то, для чего у движка нет
своей команды: `openmediad ask "громкость 3"`, `openmediad ask включи свет`.

## 2. Компонент на Go

Компонент — папка `internal/components/<имя>/` с `register.go`, который в `init()` вызывает `registry.Register`. Как устроен компонент, паспорт
и сборка — [ARCHITECTURE.md](ARCHITECTURE.md), §4; свой плеер музыки — [PLAYERS.md](PLAYERS.md). Здесь — что ядро даёт и о чём сообщает.

### Что ядро даёт (службы из `env`)

`registry.Use[Тип](env, "имя")`:

| Имя | Тип | Зачем |
|---|---|---|
| `engine` | `*engine.Engine` | свой звук: `NewStream(id, класс, источник, свойства, события)`; класс `Music` приглушается под Алису, идёт в выход по `[route]`, виден спектру |
| `control` | `*control.Hub` | команды плееру одним вызовом `Command(cmd, origin)`; подписка на события `Subscribe`; `Owns`, `Idle`, `Players` |
| `machine` | `*mediad.Machine` | автомат плееров платформы: играет ли музыка Яндекса (`Playing`), снимок плееров (`Snapshot`) |
| `led` | `led.Indicator` | сообщить, что вы играете (источник) или что звук идёт в вас (выход): подсветку рисует `led-ring` |
| `journal` | `*journal.Journal` | журнал; обычно хватает `env.Logf("имя")` |
| `swallow-voice` | `func()` | погасить ближайший голосовой ответ Алисы (вы выполнили её фразу сами) |
| `state` | `func() any` | снимок состояния демона (его показывает отладочная страница) |

### О чём ядро сообщает (методы компонента)

Демон подключает компонент по методам с точной подписью. Реализуйте нужные:

| Метод | Когда вызывается |
|---|---|
| `InterceptPhrase(reqID, text string, fast bool) (handled bool)` | окончательная фраза пользователя, раньше ответа облака; `true` — вы выполнили её сами, ответ Алисы голосом гасится. `fast` — короткая команда без «Алиса» |
| `OnReply(reqID string, directives []string)` | ответ облака на запрос целиком: имена директив |
| `OnReplyTrack(reqID, title, artist string)` | какой трек облако решило включить |
| `OnDirective(name string)` | имя каждой директивы ответа |
| `OnFocus(on bool)` | диалог с Алисой начался или кончился (музыку ядро приглушает само) |
| `Accepts(control.Origin) bool`, `State() control.State`, `Do(control.Cmd, control.Origin) error` | вы — плеер ядра ([PLAYERS.md](PLAYERS.md)) |
| `Name() string`, `Available() bool`, `Open(audio.Format) (audio.Output, error)` | вы — выход звука, его видно в `[route]` |
| `Start(ctx) error`, `Stop()` | модуль: запускается после всех, останавливается при выходе |
| `Shutdown()` | выход демона |
| `Reload(cfg any) (restart []string)` | настройки изменились на ходу |
| `StatusLine() string`, `DebugState() any` | строка в `openmediad status`, данные в `status -v` |
| `LogsDialog() bool` | просить писать реплики диалога в журнал |

**Опечатка в подписи не останется незамеченной.** Если у компонента есть метод с таким именем, но другой подписью (например,
`InterceptPhrase(reqID, text string) bool` без третьего аргумента), демон при запуске пишет в журнал предупреждение с подписью, которую он ждёт:
`openmediad logs -level warn`.

Команда терминала от компонента — `command.Register(группа, команда)` из `init()` (так появляются `openmediad bt` и `openmediad spotify`).

### Источник команд (свой ввод)

Кнопка, пульт, датчик, сеть — всё, что хочет сказать «пауза» или «дальше». Один вызов:

```go
hub, _ := registry.Use[*control.Hub](env, "control")
by, err := hub.Command(control.Next, control.API) // by: имя плеера, control.OwnerPlatform или "" (никто)
```

Знать, чей сейчас звук и как дойти до платформы, вашему коду не нужно. Если платформа узнаёт о вашем действии сама (как о кнопке на колонке),
вызывайте `hub.Do` с подходящим источником: второй раз передавать ей команду не надо.

### Вывод (своя индикация)

```go
hub.Subscribe(func(e control.Event) {
	if e.PlatformDisplay { // прошивка покажет сама
		return
	}
	// показать паузу или перемотку по-своему
})
```

Функция вызывается на каждое событие по очереди и должна возвращаться быстро.

### Свой звук

Источник — тип с методами `Format`, `Open`, `Read`, `Close` (`engine.Source`). Дальше `engine.NewStream(...)`, `Play()`, `Pause()`, `Close()`.
Громкость класса, приглушение под Алису, выбор выхода (динамики или наушники), спектр для дисплея и позицию по часам движок ведёт сам. Образцы:
`components/system-sounds` (звук из памяти), `components/spotify-soloist/pcm.go` (звук чужого процесса), `components/yandex-music` (поток из сети).
