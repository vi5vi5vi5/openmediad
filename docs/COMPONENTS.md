# Компоненты

Файл создаётся автоматически из `internal/components/catalog` (`go run ./tools/build -sync-docs`) — руками не править.

Компонент — опциональная возможность движка: своя папка в `internal/components/`, свой паспорт, своя секция в файле настроек.
Любой компонент можно не включать в сборку, и колонка не сломается: что он делал, играет штатный `mediad` (в паспорте — строка «Если убрать»).

## Классы

| Класс | Смысл |
|---|---|
| **необходимый** | то, ради чего проект существует |
| **штатный** | повторяет штатное поведение колонки |
| **вспомогательный** | для людей, не для звука: отладка, разработка |
| **необязательный** | новая возможность сверх штатной колонки |

## Профили сборки

| Профиль | Что входит |
|---|---|
| `core` | только ядро: прозрачный посредник, колонка играет штатно |
| `standard` (по умолчанию) | `yandex-music`, `alice-voice`, `system-sounds`, `display-spectrum`, `debug-page` |
| `full` | `yandex-music`, `alice-voice`, `system-sounds`, `display-spectrum`, `debug-page`, `debug-profiler`, `bt-out`, `bt-in` |

```sh
go run ./tools/build                       # профиль standard
go run ./tools/build -profile core          # только ядро
go run ./tools/build -profile full          # всё готовое
go run ./tools/build -with bt-out           # standard + компонент
go run ./tools/build -without debug-page    # standard без компонента
go run ./tools/build -list                  # эта таблица в терминале
```

## Паспорта

### `yandex-music`

| | |
|---|---|
| Название | Музыка Яндекса |
| Имя · тег сборки · настройки | `yandex-music` · `omd_yandex_music` · `[yandex-music]` |
| Вид | источник звука (откуда берётся) |
| Класс | **необходимый** — то, ради чего проект существует |
| В сборке по умолчанию | да (профиль `standard`) |
| Зрелость | проверен |
| Что делает | играет музыку Яндекса из команд платформы сам: HTTPS, расшифровка, перемотка, спектр для дисплея |
| Нужно от прошивки | GStreamer колонки (`maind --gst-launch`): декодирует AAC; системный `aplay`: вывод звука; корневые сертификаты прошивки `/system/vendor/quasar/ca-certificates.crt` (запасной набор); сеть (HTTPS до серверов Яндекса) |
| Нужно от других компонентов | — |
| Если убрать | музыку Яндекса играет штатный mediad |

### `bt-out`

| | |
|---|---|
| Название | Bluetooth-наушники: вывод звука |
| Имя · тег сборки · настройки | `bt-out` · `omd_bt_out` · `[bt-out]` |
| Вид | выход звука (куда уходит) |
| Класс | **необязательный** — новая возможность сверх штатной колонки |
| В сборке по умолчанию | нет (добавляется `-with bt-out` или профилем `full`) |
| Зрелость | опытный: проверен не полностью |
| Что делает | колонка играет в Bluetooth-наушники (A2DP): музыку, голос и звонки по маршруту `[route]`, кнопки и громкость наушников; команда `bt` |
| Нужно от прошивки | BlueZ и BlueALSA на системной шине D-Bus; системный `aplay` с плагином bluealsa; `/dev/input`: кнопки наушников (AVRCP); сервис `aliced` платформы (127.0.0.1:9875): кнопки наушников → платформе; регулятор громкости ALSA Master |
| Нужно от других компонентов | — |
| Если убрать | звук только на динамиках |
