# debug-profiler — Профилировщик Go

`pprof` на порту отладочной страницы: `/debug/pprof/*`. Для разработки. С компьютера:

```sh
go tool pprof -top http://адрес-колонки:6701/debug/pprof/profile?seconds=20
```
