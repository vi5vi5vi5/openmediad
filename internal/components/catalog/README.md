# components/catalog — паспорта компонентов

**Единственное место, где задан список компонентов.** Таблица `All` (`catalog.go`): для каждого — название, вид, **класс**, входит ли в
сборку по умолчанию, опытный ли, что требует от прошивки (`Needs`), от других компонентов (`NeedsComponents`), что будет, если его убрать.
Здесь же профили сборки `core` / `standard` / `full`.

* `catalog.go` — паспорта и профили; в `init()` передаёт список ядру (`registry.SetCatalog`).
* `passport.go` — генерация блоков «Паспорт» для `README.md` компонентов и файла `docs/COMPONENTS.md`.

Правки паспорта → `go run ./tools/build -sync-docs` (тест `TestDocsInSync` не даст забыть). Пакет не импортирует код компонентов.
