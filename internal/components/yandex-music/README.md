# yandex-music — Музыка Яндекса

Музыку Яндекса из команд платформы играет сам движок: HTTPS-поток, расшифровка AES-128, разбор MP4, декодирование AAC (GStreamer колонки),
перемотка, зеркала, спектр для дисплея.

## Что внутри

| Файл | Что делает |
|---|---|
| `fetch.go` | HTTPS-клиент с сертификатами прошивки; `Fetch` — поток трека с любого смещения (HTTP Range), перебор зеркал, расшифровка AES-128-CTR на лету |
| `source.go` | `Source`: читает `moov`, режет поток на кадры AAC, оборачивает в ADTS, отдаёт декодеру, PCM копит в `Ring`; перемотка = новая «сессия» |
| `bind.go` | переводчик «команда mediad → поток движка» (`mediad.Backend`): `Open`, `Adopt` (возобновление с паузы), `Start` / `Pause` / `Close` / `Seek` |
| `register.go` | регистрация компонента, настройки `[yandex-music]` |
| [`aac/`](aac/README.md), [`mp4/`](mp4/README.md) | ADTS и декодер AAC; таблица сэмплов MP4 |

**Использует:** `core/engine`, `core/quasar/mediad` (только `bind.go`), `libs/gstreamer`.
