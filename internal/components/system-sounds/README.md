# system-sounds — Звонки и системные звуки

Звонки таймеров и будильников играют по кругу, пока платформа не пришлёт `release`; одноразовые системные звуки (после «Алиса», отмена,
щелчок громкости, сигналы Bluetooth) — один раз. Файлы раскодируются GStreamer колонки целиком в память (кэш), частые — заранее при запуске
(`preload`).

## Что внутри

| Файл | Что делает |
|---|---|
| `path.go` | `Dir` (`/system/vendor/quasar/sounds/`), `ValidPath` — безопасные имена (путь подставляется в строку GStreamer) |
| `library.go` | `Library` / `Clip`: раскодирование файла (`filesrc ! decodebin`), кэш 6 МБ с вытеснением, `Preload` |
| `source.go` | `Source`: файл по кругу без разрыва либо один раз |
| `bind.go` | переводчик «команда mediad → поток движка» (`mediad.FileBackend`), класс `alert` |
| `register.go` | регистрация, настройки `[system-sounds]`, список `preload` |
| [`mp3/`](mp3/README.md) | сведения о MP3-файле (битрейт для диагностики событий) |

**Использует:** `core/engine`, `core/quasar/mediad` (только `bind.go`), `libs/gstreamer`.
