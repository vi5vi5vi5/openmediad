# bt-in — Bluetooth: звук с телефона через движок

Штатно звук телефона играет `bluealsa-aplay` мимо openmediad. Пока компонент работает, `bluealsa-aplay` остановлен, а PCM телефона читает
openmediad (системный `arecord`) и играет своим движком как музыку: с приглушением на время диалога, спектром для дисплея и маршрутом
`[route] music`. Управление (пауза, «дальше», громкость) остаётся у платформы.

## Что внутри

| Файл | Что делает |
|---|---|
| `btin.go` | `Source`: останавливает штатный `bluealsa-aplay`, следит за телефоном по D-Bus, читает PCM, `StatusLine`, `DebugState` |
| `recorder.go` | запуск `arecord` и его остановка (SIGINT, не SIGKILL) |
| `register.go` | регистрация, настройки `[bt-in]`, управление службой `bluealsa-aplay`, подключение команды `bt` |

**Использует:** `core/engine`, `core/speaker/aplay` (аргументы командной строки), `libs/bluez`, `libs/dbus`, `libs/bt-command`.
