# alice-voice — Голос Алисы

Ответы Алисы приходят командами `voice-chunk` как самостоятельные потоки Ogg/Opus (моно, 48 кГц, CELT); движок декодирует их **на чистом
Go** (GStreamer для этого не нужен: он тяжелее в 10 раз) и играет классом `voice`.

## Что внутри

| Файл | Что делает |
|---|---|
| `source.go` | `Source` — один ответ; **один общий** декодер на все ответы (`Shared`): новый на каждый ответ раздувал бы кучу |
| `bind.go` | переводчик «команда mediad → поток движка» (`mediad.VoiceBackend`): `Start` / `Chunk` / `EOS` / `Abort`; новый ответ вытесняет старый |
| `answervol.go` | громкость ответов: с `answer_volume = "hold"` держит громкость колонки на уровне до ответа (см. ниже) |
| `register.go` | регистрация компонента, настройки `[alice-voice]` |
| [`ogg/`](ogg/README.md), [`opus/`](opus/README.md) | разборщик Ogg; декодер Opus |

## Громкость ответов

Прошивка колонки на время каждого ответа Алисы сама меняет громкость и потом возвращает её (функция SmartVolume, секция `smart_volume` в
`/system/vendor/quasar/quasar.cfg`): по шуму в комнате тихая громкость поднимается, громкая — опускается. Решение принимается заново на каждый
ответ, поэтому соседние ответы одного диалога могут звучать по-разному. В журнале платформы это видно так (проверено 11.11.2026):

```
Estimated ambient noise volume: 46.37 dB, current volume in percent: 20, matched volume: 40
Saved volume 8
…ответ…
Restore pre-request volume
Restore volume, currentVolume=40, newVolume=20, restoreRule=save_if_manual
```

Настройка `answer_volume` (переключается на ходу, без перезапуска движка: `openmediad config set alice-voice.answer_volume hold`):

| Значение | Что происходит |
|---|---|
| `"platform"` (по умолчанию) | как решит колонка: штатное поведение |
| `"hold"` (опытное) | компонент держит громкость колонки (ALSA Master) на уровне до ответа: перемену, сделанную платформой для ответа, сразу возвращает |

Как `hold` отличает платформу от человека: платформа меняет громкость в тот же миг, когда пришёл ответ облака (по журналам разница до 10 мс), и в
ответе нет директив громкости. «Алиса, громче» (в ответе есть `sound_…` или `volume_…`), кнопки колонки и колесо наушников (ответа рядом нет)
принимаются как новая громкость. Счётчики — `openmediad status -v`, раздел `alice-voice`.

Ограничения: удерживается только регулятор колонки. Громкость Bluetooth-наушников платформа ставит им сама по AVRCP, мимо него; в наушниках
помогает другое — «ответ закончен» сообщается платформе, только когда ответ действительно отзвучал (`bt-out`, настройка `latency`), и возврат
громкости не попадает на конец ответа. **На колонке `hold` на слух ещё не проверен.**

**Использует:** `libs/alsactl` (регулятор громкости колонки, только при `hold`).
