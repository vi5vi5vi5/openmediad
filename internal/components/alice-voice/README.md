# alice-voice — Голос Алисы

Ответы Алисы приходят командами `voice-chunk` как самостоятельные потоки Ogg/Opus (моно, 48 кГц, CELT); движок декодирует их **на чистом
Go** (GStreamer для этого не нужен: он тяжелее в 10 раз) и играет классом `voice`.

## Что внутри

| Файл | Что делает |
|---|---|
| `source.go` | `Source` — один ответ; **один общий** декодер на все ответы (`Shared`): новый на каждый ответ раздувал бы кучу |
| `bind.go` | переводчик «команда mediad → поток движка» (`mediad.VoiceBackend`): `Start` / `Chunk` / `EOS` / `Abort`; новый ответ вытесняет старый |
| `register.go` | регистрация компонента, настройки `[alice-voice]` |
| [`ogg/`](ogg/README.md), [`opus/`](opus/README.md) | разборщик Ogg; декодер Opus |
