# soundcloud — SoundCloud по ссылке

Плеер движка: включает трек, плейлист, альбом или треки исполнителя SoundCloud по ссылке из браузера или приложения
(«Поделиться → Скопировать ссылку»). Ссылку приносит ядро ([музыка по ссылке](../../core/control/README.md)): `openmediad player link ССЫЛКА`
в терминале или `!play ССЫЛКА` в чате конференции ([meetup](../meetup/README.md)). Пауза, «дальше» и «назад» — через ядро команд, как у Spotify:
кнопки колонки и наушников, голос, `openmediad player`, `!pause` и `!next` в чате.

## Как устроено

| Файл | Что делает |
|---|---|
| `api.go` | внутренний API сайта (`api-v2.soundcloud.com`): `resolve` ссылки, догрузка треков плейлиста (`/tracks?ids=`), треки исполнителя, выбор потока и его адрес; client_id из настроек или найденный на сайте (`discover`, помнится в `state/soundcloud.json`, при 401/403 ищется заново) |
| `source.go` | звук трека: плейлист HLS (запись, сегменты fMP4 по 10 с) → `libs/hls` (кадры AAC с заголовком ADTS) → декодер AAC `libs/aac` (GStreamer колонки, 48 кГц стерео) → буфер PCM |
| `player.go` | очередь и поток движка на трек (класс «музыка», спектр, возврат звука при паузе); `control.Player` (`Accepts/State/Do`), `control.LinkPlayer` (`LinkHosts/PlayLink`), подсветка, строка `status` |
| `register.go` | настройки `[soundcloud]`, HTTPS-клиент (сертификаты прошивки, если системных нет) |

Что видно в SoundCloud сейчас (проверено 20.11.2026 на открытом треке): у трека три потока — `aac_160k` и `aac_96k` (HLS, AAC-LC в fMP4,
`EXT-X-MAP` + сегменты `.m4s`, без шифрования) и `abr_sq` (главный плейлист). MP3 SoundCloud больше не отдаёт. Компонент берёт лучший целый
(не `snipped`) поток AAC. Адрес плейлиста и сегментов подписан и действует около двух часов.

Чего не делает: треки только для подписчиков Go+ (у них целиком есть лишь отрывок) пропускаются; недоступные в стране (`policy: BLOCK`) —
тоже. Перемотки нет. Подсветка — цвет `#ff5500` на кольце (настраивается в `led-ring`), дисплей и спектр платформы о SoundCloud не знают
(как у Spotify без «виртуального плеера»).

## Настройки

```toml
[soundcloud]
enabled = true
client_id = ""     # пусто — найти на soundcloud.com самому
max_tracks = 200   # сколько треков плейлиста или исполнителя ставить в очередь
proxy = ""         # http://хост:порт или socks5://хост:порт — все запросы к SoundCloud (API, сайт, CDN)
```

**Из России нужен прокси.** 20.11.2026 с колонки (домашний интернет, без VPN) соединения с soundcloud.com сбрасывались сразу после TLS
(«connection reset by peer»), а с компьютера через VPN всё работало. С прокси (тот же, что `web_proxy` у Spotify) трек открылся и заиграл.

client_id можно взять и вручную: открыть soundcloud.com в браузере, инструменты разработчика → «Сеть», любой запрос к `api-v2.soundcloud.com`,
параметр `client_id`. Заданный вручную client_id компонент не меняет, даже если он устарел.

## Заглушки

| Что | Сейчас | Где закрывать |
|---|---|---|
| **Долгая пауза** | подписи ссылок на сегменты живут около двух часов: после паузы дольше трек оборвётся и заиграет следующий | `player.go`: при продолжении после долгой паузы заново взять адрес потока и начать с позиции (нужна перемотка по сегментам в `source.go`) |
| **Перемотка** | нет | `source.go`: `Seek` — с нужного сегмента HLS (длительности известны из плейлиста) |
| **Дисплей и спектр платформы** | не показывают SoundCloud | `mediad.Machine.SetVirtual`, как `spotify-soloist/virtual.go` |
| **Вход в аккаунт** | только открытые треки; свои лайки и закрытые плейлисты недоступны | OAuth-токен пользователя в заголовке `Authorization` |
| **Поиск по названию** | только ссылки | `api-v2 /search/tracks` и «включи … на саундклауде» по образцу `spotify-soloist/request.go` |

## Как проверить

* `go test ./internal/components/soundcloud` — поддельный SoundCloud (`httptest`): resolve, плейлист с догрузкой треков, выбор потока, client_id
  с сайта и его замена после 401, очередь, пауза, «дальше», «назад», договор плеера ядра (`controltest.CheckPlayer`).
* Живая проверка API с этого компьютера: `OMD_SC_LIVE=https://soundcloud.com/… go test -run TestLive -v ./internal/components/soundcloud` —
  находит client_id, разбирает ссылку, качает первые сегменты и проверяет кадры AAC.
* На колонке без звука: `openmediad-dev play-soundcloud -link ССЫЛКА -silent` — весь путь с настоящим GStreamer, PCM считается и выбрасывается.
