# components/included — что войдёт в бинарник

По файлу `include_<имя>.go` на каждый готовый компонент: тег сборки `omd_<имя>` (дефис в имени → `_`) и пустой импорт пакета компонента,
чей `init()` его регистрирует. Без тегов пакет пуст — получается ядро без компонентов (прозрачный посредник).

Теги вручную писать не нужно: `go run ./tools/build` собирает их из профиля (`core` / `standard` / `full`) и `-with` / `-without`.
Тест `included_test.go` следит, чтобы файлы совпадали с каталогом.
