# debug-page — Отладочная веб-страница

Страница с живым журналом и пояснениями, только чтение. Вместе с ней демон пишет в журнал реплики диалога с Алисой (распознанные фразы).

## Что внутри

| Файл | Что делает |
|---|---|
| `server.go` | HTTP: `/` (страница), `/api/log` (журнал, `format=ndjson`), `/api/stream` (SSE, не больше 6 слушателей), `/api/state`; `AddHandlers` — точка расширения (её использует `debug-profiler`) |
| `page.html` | самодостаточная страница (встраивается в бинарник) |
| `register.go` | регистрация, настройки `[debug-page]` (`listen`, `cors`); `LogsDialog` — просит писать реплики диалога в журнал |
