# meetup/proto/prototest — поддельный сервер MeetUp

Для тестов клиента (`meetup/proto`) и компонента (`meetup`): принимает WebSocket, отвечает на `join` (в истории чата лежит команда, которую клиент
выполнять не должен), возвращает чат всем участникам, запоминает состояние «микрофона» и звуковые кадры, умеет отказать во входе (`RefuseJoin`)
и оборвать связь (`Drop`).

Говорит на протоколе настоящего сервера только в объёме, который нужен колонке; совместимость с настоящим сервером проверяется отдельно, вживую
(см. [README компонента](../../README.md#как-проверить)).
