# internal — весь код продукта

Код разложен по **трём зонам** (плюс инструменты разработчика). Зона говорит, насколько код важен и что от него зависит.

| Папка | Что это | Всегда в бинарнике? |
|---|---|---|
| [`core/`](core/README.md) | **ядро**: без него движок не существует | да |
| [`components/`](components/README.md) | **компоненты**: опциональные возможности, у каждого паспорт | только выбранные при сборке |
| [`libs/`](libs/README.md) | **общие библиотеки** для компонентов (GStreamer, D-Bus, BlueZ, команда `bt`) | только если нужны вошедшим компонентам |
| [`devtools/`](devtools/README.md) | код инструментов разработчика (`openmediad-dev`) и тестов | нет, в продукт не входит |
| [`architecture/`](architecture/README.md) | тест, который держит эти правила | нет, только тесты |

**Правила зависимостей** (проверяет `architecture/architecture_test.go`):

- `core` импортирует только `core` — ни одного имени компонента в коде ядра нет;
- `libs` — `core` и `libs`;
- компонент — `core`, `libs`, свои подпакеты и компоненты, указанные в его паспорте как зависимость;
- `devtools`, `cmd`, `tools` — что угодно.

Карта всего проекта — [docs/MAP.md](../docs/MAP.md); паспорта компонентов — [docs/COMPONENTS.md](../docs/COMPONENTS.md).
