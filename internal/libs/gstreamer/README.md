# libs/gstreamer — запуск встроенного GStreamer

**Что такое GStreamer.** Мультимедийный каркас, который уже есть в прошивке: штатный `mediad` играет всё через него. Он вшит в `maind` и
запускается как `maind --gst-launch "<конвейер>"`.

**Что делает здесь.** Только декодирует сжатый звук в PCM: мы запускаем `maind --gst-launch` дочерним процессом, подаём данные в stdin (или путь
к файлу), PCM читаем из **третьего дескриптора** (`fd 3`): stdout и stderr у `maind` заняты его журналом.

**Правила.** На неверном конвейере процесс **не завершается сам** (висит ≈30 МБ), поэтому запускать только со сторожем по времени; в отличие
от `aplay`, ему можно слать SIGKILL (общий смеситель звука он не держит).

* `gst.go` — `MaindPath`, `RawOut(rate, channels)` (хвост конвейера в `fd 3`).
* `process_linux.go` / `process_other.go` — `Process` (`Start`, `Done`, `Wait`, `Kill`, `Close`); вне Linux — заглушка.

**Кому нужно:** `yandex-music` (AAC), `system-sounds` (файлы звуков). Голос Алисы GStreamer не использует.
