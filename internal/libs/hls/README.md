# hls — приём звукового потока HLS

Радиостанции, которые включает Алиса, вещают по HLS (RFC 8216): плейлист `.m3u8` со списком коротких сегментов, который станция
всё время дополняет. SoundCloud отдаёт так же и записи (плейлист с `EXT-X-ENDLIST`, сегменты fMP4). Пакет читает такой поток и отдаёт сжатый звук по порядку. Декодирования здесь нет.

| Файл | Что делает |
|---|---|
| `playlist.go` | `Parse`: главный плейлист (варианты битрейта) и медиа-плейлист (сегменты, номера, длительность, конец записи); `Best` выбирает вариант для звука — самый большой битрейт без видео |
| `stream.go` | `Open` и `Stream.Next`: сегменты по порядку; у живого потока старт за три сегмента до края, ожидание новых (плейлист перечитывается раз в половину длительности сегмента), переход к свежим после долгой паузы или сброса нумерации |
| `extract.go` | `Extractor`: звук из сегмента — из MPEG-TS (таблицы PAT и PMT, пакеты PES), из fMP4 или из «голого» AAC и MP3 с меткой ID3; на выходе кадры ADTS или MP3, годные декодеру как есть |
| `fmp4.go` | fMP4 (`EXT-X-MAP`): из сегмента инициализации (`moov`) — дорожка AAC и её AudioSpecificConfig (`esds`), из фрагментов (`moof` + `mdat`) — кадры по таблице `trun`; каждый кадр получает заголовок ADTS. `Stream.Next` отдаёт сегмент инициализации вместе с первым сегментом (и когда `EXT-X-MAP` сменился) |

```go
st, err := hls.Open(ctx, "https://станция/playlist.m3u8", hls.Options{Client: client})
var ex hls.Extractor
for {
	seg, err := st.Next(ctx) // ждёт следующий сегмент живого потока
	es, err := ex.Push(seg)  // звук из сегмента; ex.Codec() — AAC или MP3
	decoder.Write(es)
}
```

Как ведёт себя при сбоях:

- сегмент не скачался — пропускается; больше трёх подряд — ошибка;
- сегмента на сервере уже нет (после долгой паузы окно ушло вперёд) — поток встаёт у свежего края;
- плейлист не обновляется 30 с — ошибка «поток остановился» (а не вечное ожидание);
- `EXT-X-ENDLIST` — `io.EOF` после последнего сегмента.

**Не поддержано** (ошибка `ErrUnsupported`, вызывающий откатывается на штатный плеер): шифрованные сегменты (`EXT-X-KEY`, `enca`, `senc`),
сегменты-куски файла (`BYTERANGE`), звук не AAC и не MP3 (AC-3, AAC в LATM, Opus в fMP4).

Ссылки в журнал и в тексты ошибок не попадают: в них бывают метки сессии слушателя. Станции привязывают сессию и к куке, поэтому у
каждого потока своя банка кук.

Кому нужна: `yandex-music` (радио из команд платформы: `radio.go`), `soundcloud` (треки). Тесты — `hls_test.go`: плейлисты по образцу настоящей станции,
собранный в тесте MPEG-TS, поддельная станция с живым окном; `TestLiveStation` — проверка на настоящей станции (по переменной `OMD_HLS_URL`).
