# libs/bluez — BlueZ и BlueALSA

Bluetooth колонки через `libs/dbus`: адаптер, устройства, спаривание (`PairAndTrust`), подключение, громкость PCM, звуковые потоки BlueALSA,
а также «спрятать / показать транспорт» платформе (BUS-PROTOCOL.md, §2.7б).

Видимостью колонки для телефонов владеет платформа («включи / выключи блютуз»); пакет её не трогает.

**Кому нужно:** `bt-out`, `bt-in`, `bt-command`.
