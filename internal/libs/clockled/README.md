# libs/clockled — дисплей с часами Станции Мини 3

32 светодиодных сегмента (`/sys/class/leds/bergamot:white:clock<имя>/brightness`, яркость 0…255): четыре семисегментные цифры, двоеточие (`DH`, `DL`), средняя точка (`DM`) и значок
градуса (`DEGREE`). Имена сегментов — буква A…G и номер цифры 0…3 (`A0` — верх первой цифры слева); порядок в кадре: цифры 0…3 по A…G, затем `DH`, `DL`, `DM`, `DEGREE`.
Сегменты знака: A — верх, B — верх справа, C — низ справа, D — низ, E — низ слева, F — верх слева, G — середина.

* `OpenSysfs()` → `Read()` / `Write(Frame)` (пишет только изменившиеся сегменты); `Names`, `Index`.
* `LoadAnim(каталог, имя)` читает анимацию прошивки `<имя>.binscled.zst` (`AnimDir` = `/system/vendor/quasar/ledpatterns/clock`); `DecodeAnim`, `ParseAnim`.
  Для плеера есть три: `AnimPause`, `AnimNext`, `AnimPrevious` (у «продолжить» анимации дисплея нет).
* `Player` проигрывает анимацию в фоне (`Play`), перед первым кадром запоминает, что горело (время), и по окончании возвращает; перед каждым кадром проверяет, что на дисплее то,
  что записали мы, и если прошивка нарисовала своё (спектр, смена минуты, анимация Алисы), уступает и ничего не возвращает. Новая анимация заменяет играющую.

## Формат файла `.binscled.zst`

zstd с окном 128 МБ (сами файлы крошечные), внутри поток кадров по 35 байт:

| Байты | Что |
|---|---|
| 0 | флаг; у первого кадра 1 — анимация зациклена (анимации Алисы, звонок, настройка), у плеера 0 |
| 1…32 | яркость 32 сегментов в порядке `Names` |
| 33…34 | длительность кадра в миллисекундах, старший байт первым (кадры по 20 мс, «пик» паузы — 1700 мс, хвост перемотки — 520 мс чёрным) |

Разобрано по файлам `player_pause` (26 кадров: пауза плавно загорается за 280 мс на `B1 C1` и `E2 F2`, держится 1,7 с, гаснет), `player_next_track` и `player_previous_track` (по 43 кадра: вертикальные
полосы `E2 F2` → `B2 C2` → `E3 F3` → `B3 C3` от центра вправо, и зеркально `B1 C1` → `E1 F1` → `B0 C0` → `E0 F0` влево) и сверено с тем, что видно на дисплее. Остальные файлы
каталога (`alice_listening`, `alice_thinking`, `alice_speaking`, `ringing`, `boot`, `blink` …) того же формата.

Распаковка — `github.com/klauspost/compress/zstd` (лежит в `vendor/`); читается только на колонке из файлов прошивки, в проект сами анимации не входят.

Тесты: `go test ./internal/libs/clockled/`; тест на настоящих файлах прошивки идёт на колонке или с `OMD_CLOCK_ANIMS=каталог` (файлы `<имя>.binscled.zst`), иначе пропускается.

**Кому нужно:** `led-ring`.
