# pcmstream — звук от чужого процесса как источник движка

`pcmstream.Source` — `engine.Source`, в который кто-то пишет PCM (S16LE) потоком, а движок читает. Общий кирпич для компонентов,
у которых звук отдаёт другой процесс (Spotify: Soloist через шим, librespot через канал; приём звука по сети).

| Что | Зачем |
|---|---|
| `Write` блокируется, когда накоплено больше потолка (`maxBuffered`) | чужой процесс не убегает вперёд: пауза и перемотка быстрые |
| `Flush` | выбросить накопленное (перемотка, смена трека) |
| `Rewind` (`engine.Rewinder`) | вернуть последние отданные байты: при паузе звук, не дошедший до динамика, не пропадает |
| `Wake` (`engine.Waker`) | прервать ожидающее чтение (пауза), данные целы |
| `CloseWrite` | данных больше не будет: после остатка чтение вернёт `io.EOF` (конец трека) |

Писать нужно целыми кадрами. Тесты — `pcmstream_test.go`.
