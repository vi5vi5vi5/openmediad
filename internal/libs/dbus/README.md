# libs/dbus — клиент системной шины D-Bus

Свой маленький клиент (без библиотек): вызов методов, ответы, сигналы. Нужен, чтобы управлять Bluetooth так же, как платформа: BlueZ и
BlueALSA живут на системной шине колонки (`/run/dbus/system_bus_socket`, вход только EXTERNAL).

* `conn.go` — `Conn`: соединение, авторизация, `Call`, `Emit`, `Subscribe`.
* `message.go` — разбор и сборка сообщений D-Bus (выравнивание, типы, массивы, словари).
