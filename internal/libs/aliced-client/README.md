# libs/aliced-client — клиент aliced

Команды плееру от имени клиента `aliced` (порт 9875), как пункты `maind --cli`: `Send` (пауза, продолжить, дальше, назад), `Ask` (текстовый
запрос Алисе — то же, что сказать фразу). Платформа выполняет их так же, как нажатие кнопки.

**Кому нужно:** `bt-out` — кнопки наушников.
