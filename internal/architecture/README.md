# architecture — тест раскладки

Кода нет, только `architecture_test.go`. Тест читает импорты всех пакетов в `internal/` и падает, если:

1. `core` импортирует что-то, кроме `core`;
2. `libs` импортирует компонент;
3. компонент импортирует другой компонент, которого нет в его паспорте как зависимости (`NeedsComponents`);
4. в коде `core` встречается имя компонента строкой (защита от возврата «имён в ядре»);
5. в какой-либо папке с кодом нет `README.md`.

Так раскладка не расползается: нарушение видно сразу при `go test ./...`.
