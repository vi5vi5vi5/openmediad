# core/engine — ядро звука

Поток звука: **источник → громкость класса → вывод**. Движок ничего не знает о шине Quasar, о конкретных источниках и выходах — только
об интерфейсах (`Source`, `Router`, `audio.Output`).

| Файл | Что делает |
|---|---|
| `engine.go` | `Engine`; классы потоков `Music` / `Voice` / `Alert`; интерфейс `Source` (+ необязательные `Seeker`, `Rewinder`, `Waker`, `SpectrumTapper`); `Router`; громкость класса — приглушение музыки на время диалога; `Reroute` |
| `stream.go` | `Stream`: `Open` (источник готовится в фоне), `Play`, `Pause`, `Seek`, `Close`, `Pos` — позиция по **часам**, а не по записанным байтам |
| `loop.go` | цикл вывода порциями по 50 мс: нарастание, громкость, спектр, запись в вывод; при паузе возвращает источнику непрозвучавшее; если вывод отказал — переезжает на следующий выход маршрута |
| `spectrum.go` | связка цикла вывода с анализатором спектра (когда объявлять старт, продолжение, остановку) |

**Зависит от:** `audio`, `spectrum`, `platform/clock`. **Кто использует:** `daemon`, компоненты-источники (`yandex-music`, `alice-voice`, `system-sounds`, `bt-in`).
