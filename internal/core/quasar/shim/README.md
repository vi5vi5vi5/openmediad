# quasar/shim — прозрачный посредник

Каждое входящее соединение платформы получает своё исходящее к настоящему `mediad` (с адреса `127.0.0.2`, чтобы правило iptables не
заворачивало самого шима). Кадры пересылаются байт в байт.

| Файл | Что делает |
|---|---|
| `shim.go` | `Proxy`: `Intercept` видит кадр до отправки и может его «съесть»; `Tap` наблюдает; `Broadcast` — событие всем клиентам; `ForwardTo` — вернуть команду настоящему сервису; `Run` — пока `mediad` не отвечает, порт закрыт и ядро отказывает клиентам, как у настоящего сервиса |
| `stats.go` | `Stats` — сводка по типам кадров и гистограмма задержки шима (для инструментов) |

**Правило:** перехватчик не блокирует — всё долгое в отдельных горутинах; буфер кадра принадлежит шиму (что нужно позже — копировать).
