# core/quasar — язык шины Quasar и эмуляция штатного плеера

Всё, что связано с протоколом платформы. Схем в прошивке нет, протокол восстановлен по записям трафика; справочник —
[docs/BUS-PROTOCOL.md](../../../docs/BUS-PROTOCOL.md).

| Папка | Что это |
|---|---|
| [`pb/`](pb/README.md) → [`wire/`](wire/README.md) → [`msg/`](msg/README.md) | три ступени разбора: protobuf без схем → кадры и конверт → типизированные «окна» на сообщения |
| [`shim/`](shim/README.md) | посредник между платформой (порт 19906) и настоящим `mediad` (порт 9906) |
| [`mediad/`](mediad/README.md) | **эмуляция `mediad`**: автоматы плееров «музыка / голос / звонки», события байт в байт |
| [`explain/`](explain/README.md) | пояснения простыми словами для журнала (без секретов) |
| [`observe/`](observe/README.md) | клиент-наблюдатель: читает рассылки сервисов шины (диалог Алисы) |
