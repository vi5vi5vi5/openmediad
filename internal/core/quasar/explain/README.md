# quasar/explain — пояснения для журнала

Что за кадр и что с ним сделал движок — простыми словами. **Секреты (ключи потоков, подписанные ссылки, JSON директив, содержимое
голосовых чанков) сюда не попадают** — берутся только идентификаторы, названия, хост CDN, размеры, состояния.

* `explain.go` — `InfoOfCommand`, `InfoOfEvent`, `DescribeFrame`.
* `daemon.go` — записи журнала демона: `Note` (решения автомата), `Intercepted`, `Synthesized`.
