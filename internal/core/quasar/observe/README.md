# quasar/observe — наблюдатель за шиной

Подключается к сервису шины как обычный клиент и читает его рассылки (ничего не отправляет). Демон так следит за диалогом Алисы
(`daemon/aliced.go`), инструменты разработчика — за всей шиной.

* `observe.go` — `Observer` (`Targets`, `OnLine`, `OnReply`, `OnPhrase`: окончательная фраза пользователя, один раз на запрос, ≈1 с до ответа облака).
* `describe.go` — `Describe`: кадр одной строкой.
