# quasar/mediad — эмуляция штатного плеера

Принимает команды платформы и выпускает события плеера **тем же языком, байт в байт**. Звук не играет — отдаёт его бэкендам
(`Backend`, `VoiceBackend`, `FileBackend`), которые реализуют компоненты. Правила выведены из записей живого трафика и сверены с
ними побайтно (золотые тесты).

| Файл | Что делает |
|---|---|
| `machine.go` | `Machine` — набор плееров: `Handle` (взять команду или пропустить), `Focus` (приглушение), `Handoff` (мягкая передача плееров `mediad` при остановке), `Snapshot` |
| `audio.go`, `audio_events.go` | плеер **музыки** (вид 1): `Prefetch`, `Play`, `Pause`, `Release`, `Crossfade`, `Seek`; события по таймерам; ответы бэкенда `Opened` / `Failed` / `Finished` |
| `voice.go` | плеер **голоса Алисы** (вид 2): `voice-start` / `voice-chunk` / `voice-eos` |
| `file.go` | плеер **файлов** (вид 4): звонки по кругу и одноразовые системные звуки |
| `event.go`, `plain_event.go` | сборка событий плееров (тип 127): музыкальные и «простые» (голос и файлы) |
| `lifecycle.go` | таймеры плеера и возврат команд настоящему `mediad` (откат) |
| `nobackend.go`, `util.go` | заглушка музыки; диагностика, UUID, `vsid` |

**Откат:** если бэкенд не смог открыть поток, автомат возвращает команду настоящему `mediad` — поэтому любой компонент может отказаться от работы.
