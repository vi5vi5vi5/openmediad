# core/quasar/buttons — кнопка Алисы и жесты по колонке

Нажатие кнопки и проведение по верху колонки платформа превращает в команды своему плееру («Toggle play/pause», «Request next song»,
«Request previous song», `buttons_actions.cpp` в `maind.log`). Своего плеера у Spotify для неё нет: пауза не доходит, а жест запускает у
облака очередь Яндекс.Музыки. На шине mediad от этих действий не остаётся ничего, поэтому единственный след — строка в логе платформы,
которая появляется за несколько миллисекунд до запроса облаку.

* `Parse(строка)` узнаёт действие (`Toggle`, `Next`, `Prev`).
* `Watcher` читает лог с конца (прошлые нажатия не повторяются), каждые 50 мс, переживает ротацию `maind.log`, ждёт конца недописанной строки
  и вызывает `OnAction`.

Демон запускает его, только если есть компонент с `OnButton(buttons.Action) bool` (сейчас `spotify-soloist`); первый, кто выполнил
действие, останавливает обход (`core/daemon/buttons.go`).

Тесты: `go test ./internal/core/quasar/buttons/`.
