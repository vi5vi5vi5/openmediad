# core/daemon — демон

`openmediad run`. Единственное место, где всё соединяется: настройки → журнал → движок → шим и автомат `mediad` → сокет команд →
компоненты. Остальные пакеты знают друг о друге только через интерфейсы.

| Файл | Что делает |
|---|---|
| `app.go` | `Run`: порядок запуска и остановки; адреса шима (`19906` → `9906`, исходящие с `127.0.0.2`); сигналы: SIGTERM — мягкая передача плееров штатному `mediad`, SIGHUP — перечитать настройки |
| `components.go` | создаёт включённые компоненты и подключает их **по интерфейсам** (`mediad.Backend/VoiceBackend/FileBackend`, выход звука, «модуль» с `Start/Stop`, `StatusLine`, `OnDirective`, `InterceptPhrase`, `OnReply`, `OnFocus`, `LogsDialog`, `Reload`; плеер движка — `control.Player`); ошибка компонента демон не роняет |
| `hooks.go` | проверка точек расширения: метод компонента назван как точка расширения, но подпись другая — предупреждение в журнал (иначе он молча не вызывался бы) |
| `control.go` | ответы на команды сокета: `status`, `logs`, `follow`, `reload`, `control`, `players`, `events`, `ask`; что настройки применяются на ходу, а что после перезапуска |
| `api.go` | управление для своих программ ([docs/API.md](../../../docs/API.md)): команда плееру, «кто играет», рассылка событий подписчикам, фраза Алисе |
| `remote.go` | пульт музыки платформы для ядра команд (`control.PlatformRemote`): команда, которую не взял плеер движка, уходит платформе через aliced, как кнопка колонки |
| `focus.go` | начало и конец диалога с Алисой: сообщение компонентам (`OnFocus`) и подписчикам сокета; музыку на это время приглушает ядро (`Machine.MusicGain` в `app.go`) |
| `stock.go` | учёт работы штатного `mediad`: что он сыграл сам, какие команды движок пропустил и вернул (строка «штатный» в `status`); список того, чего не хватает до режима replace |
| `router.go` | выбор выхода под класс звука по `[route]`: первый доступный из списка; выходы компонентов подключаются по имени |
| `intercept.go` | что делать с каждым кадром платформы: отдать автомату (штатному `mediad` не пересылать) или пропустить; запись кадров в журнал |
| `aliced.go` | слежение за диалогом Алисы: реплики — в журнал (если компонент просит); окончательные фразы и имена директив управления плеером — ядру команд, остальное (`InterceptPhrase`, `OnDirective`) — компонентам |
| `players.go` | плееры движка и ядро команд ([core/control](../control/README.md)): уступка звука (`Hub.Run`), команды платформы виртуальному плееру, журнал выполненных команд |
| `buttons.go` | кнопка Алисы и жесты по колонке (видны только в `maind.log`, [core/quasar/buttons](../quasar/buttons/README.md)) — командами плееру в [core/control](../control/README.md); лог читается, только если в сборке есть плеер движка |
| `gate.go` | шлюз голоса: гасит ответ облака на фразу, которую выполнил компонент (голос не звучит, автомат получает те же события «запущен, закончен») |

**Зависит от:** почти всего из `core`. **Кто использует:** `cli/run.go`. Новых имён компонентов здесь быть не должно.
