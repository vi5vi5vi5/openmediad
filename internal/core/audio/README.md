# core/audio — общие кирпичики звука

Ни от чего своего не зависит, поэтому его импортируют все. Внутри движка звук всегда PCM S16LE, 48 кГц.

| Файл | Что делает |
|---|---|
| `audio.go` | `Format` (`Stereo48`, `Mono48`), `Info`, интерфейс **`Output`** (`Write` / `Drain` / `Abort`) — договор между движком и выходами; `ErrWake`, `ErrStopped` |
| `gain.go` | `ApplyGain` (целочисленная громкость с плавным переходом), `FadeIn`, `DB` |
| `ring.go` | `Ring` — ограниченный буфер между декодером и выводом: блокирует запись (давление доходит до скачивания), хранит историю для `Rewind` |
