# platform/install — установка и удаление

Ошибка на любом шаге установки — откат уже сделанного (каждый шаг кладёт в стек свой откат).

* `install.go` — `Install`: бинарник → `/data/opt/openmediad`, страж, настройки; затем rootfs в одной правке.
* `manifest.go` — манифест бэкапа (`backup/manifest.json`): путь, был ли файл, sha256 оригинала и записанного.
* `rootfs.go` — правка корня: remount rw → правка → sync → remount ro (корень не остаётся в rw даже при ошибке).
* `uninstall.go` — возврат по манифесту со сверкой sha256; файлы, изменённые после установки, не трогаются.
