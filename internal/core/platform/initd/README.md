# platform/initd — страж и автозапуск

Шаблоны, встроенные в бинарник (`go:embed`) и записываемые на колонку командами `start` и `install`.

* `guard.sh` — **страж** на busybox `sh`: ставит правило iptables, запускает демон, перезапускает после падения (через 2, 4, 8… с); после
  `max_crashes` быстрых падений подряд сдаётся до перезагрузки. Демон завершился — правило снимается сразу, и колонка играет штатно.
* `initd.sh` — `/etc/init.d/S98openmediad`: запускает стража при загрузке.
* `initd.go` — подстановка путей в шаблоны.
