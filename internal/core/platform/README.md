# core/platform — колонка как система

Факты и действия над окружением колонки: где что лежит, установка с откатом, страж, iptables, штатный `mediad`. Пакеты маленькие
и независимые; ими пользуются в основном команды терминала.

| Папка | Что делает |
|---|---|
| [`layout/`](layout/README.md) | где на колонке лежат файлы openmediad |
| [`device/`](device/README.md) | колонка ли это, модель и прошивка, права root |
| [`stock/`](stock/README.md) | штатный `mediad`: найти, перезапустить, посчитать соединения платформы |
| [`iptables/`](iptables/README.md) | правило, которое ведёт платформу через шим |
| [`initd/`](initd/README.md) | шаблоны стража `guard.sh` и скрипта автозапуска |
| [`install/`](install/README.md) | установка с бэкапом и удаление без следа |
| [`proc/`](proc/README.md) | процессы и память из `/proc` |
| [`disk/`](disk/README.md) | свободное место и режим монтирования корня |
| [`clock/`](clock/README.md) | монотонные часы (та же шкала, что в `/proc/asound`) |
