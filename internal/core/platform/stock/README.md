# platform/stock — штатный mediad

Найти процесс `maind --mediad`, перезапустить его, посчитать соединения платформы с плеером (через шим на порту 19906 / напрямую на 9906,
по `/proc/net/tcp`; норма — 4). `Rerouter` дожидается, пока платформа пойдёт через шим, и при необходимости перезапускает `mediad`.
