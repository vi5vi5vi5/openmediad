# core/control — единая дверь для команд плееру

Пауза, продолжить, дальше, назад могут прийти откуда угодно: от кнопок и жестов на колонке, от кнопок наушников, голосом. Раньше каждый
источник сам решал, какому плееру отдать команду, и у каждого плеера были свои копии правил «чей сейчас звук» и «не повторилась ли команда».
Теперь источник говорит только `hub.Do(команда, откуда)`.

```
кнопки наушников (bt-out) ─┐
кнопки и жесты на колонке ─┼─→ Hub.Do ─→ плеер 1? ─→ плеер 2? ─→ … ─→ никто: источник делает по-старому
голос (пока в плеере)     ─┘                (первый, кому команда принадлежит, выполняет)
```

* `Cmd` — `Pause`, `Resume`, `Toggle`, `Next`, `Prev`.
* `Origin` — откуда: `Speaker`, `Headphones`. `PlatformReacts()` говорит, видит ли то же нажатие платформа: кнопки колонки видит (и запросит у
  облака очередь Яндекса на жест, и поставит на паузу свой плеер), наушников нет.
* `Player` — `Handle(cmd, origin) bool`: выполнить, если звук сейчас его; `false` — не его. Сейчас плеер один: `spotify-soloist`.
* `Hub` — собирает плееры (демон добавляет каждый компонент, который умеет `Handle`) и раздаёт команды. Служба ядра `"control"` для компонентов.

Не взял никто — значит, играет Яндекс.Музыка или ничего не играет, и источник поступает как раньше (наушники отдают команду платформе).

Тесты: `go test ./internal/core/control/`.
