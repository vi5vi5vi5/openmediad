# core/journal — журнал

Кольцо последних N записей в памяти (по умолчанию 2000) + подписчики. Запись: время, уровень (`trace` / `info` / `warn` / `error`),
источник, сообщение, **пояснение простыми словами**, данные без секретов. Медленный подписчик пропускает записи, а не тормозит движок.

* `journal.go` — `Journal`, `Entry`, `Log` / `Logf` / `Since` / `Subscribe`.
* `file.go` — `FileWriter`: файл журнала с ротацией (по умолчанию выключен: флеш не изнашивается).
