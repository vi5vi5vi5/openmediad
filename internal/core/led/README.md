# core/led — панель индикации

Общая «доска объявлений»: модули сообщают, **что они делают**, не заботясь, как это показать.

* `Indicator` — то, чем пользуются модули: `On(роль, имя, предложенный цвет)` и `Off(роль, имя)`. Роль `Source` — кто играет музыку, `Output` — куда она идёт.
* `Panel` — реализация, которую создаёт демон (служба `"led"` в `registry.Env.Services`). По роли показывается самая недавно включённая запись.
* `Panel.Watch(f)` — подписка для того, кто рисует (`led-ring`): `f` получает текущее состояние сразу и каждое изменение; вызывается без замков и не должен блокироваться.

Нет компонента подсветки — панель просто хранит состояние, модулям проверять ничего не нужно. Выходы звука (`bt-out`, `speaker`) отмечает сам демон: роутер видит, в какой выход открыт поток
музыки. Выход может предложить цвет через `LEDColor() led.Color`.
