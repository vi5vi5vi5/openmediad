# core/spectrum — математика спектра

`Analyzer`: БПФ на 1024 отсчёта, 513 полос, окно Хэмминга, интервал 40 мс — ровно как элемент `spectrum` штатного GStreamer-плеера
(поэтому дисплей рисует то же самое). Сюда же — тип `Event` (старт / кадр / остановка / продолжение потока спектра).

Это только вычисление. Отправка кадров платформе — компонент [`display-spectrum`](../../components/display-spectrum/README.md).
Пакет нужен ядру, потому что его вызывает `engine`.
