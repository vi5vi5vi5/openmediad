# devtools/capture — записи трафика

* `pcap.go` — чтение записей `tcpdump` (classic pcap) с разбором TCP на кадры шины.
* `framelog.go` — свой формат обезличенных записей `.omdf` (так они лежат в `testdata/`); `Recordings` — где искать записи для тестов.
* `ports.go` — порты сервисов шины.

В демон не входит; нужен инструментам разработчика и золотым тестам автомата `mediad`.
