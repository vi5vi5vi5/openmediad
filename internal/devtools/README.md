# devtools — инструменты разработчика

Код для `cmd/openmediad-dev` и для тестов; в продукт (`openmediad`) не входит.

| Файл / папка | Что делает |
|---|---|
| `pcap.go` | разбор записи трафика шины: команды и события плеера, дерево полей, выгрузка голосовых чанков в `.ogg` |
| `timeline.go` | сжатая шкала команд и событий плеера — то, что видела платформа |
| `shimcheck.go` | сверка кадров обеих сторон шима и добавляемой им задержки по записи tcpdump |
| `sanitize.go` | обезличивание записи для `testdata/`: ссылки, ключи, идентификаторы, названия, голос |
| [`capture/`](capture/README.md) | чтение записей трафика (pcap и свой формат `.omdf`); нужно и золотым тестам ядра |
